粵字 CantoCards v0.3
====================

主要更新
1. 渐进字池：起步高频（171 张）→ 日常核心（648 张）→ 实用常用（1375 张）→ 完整字表；默认“自动渐进”。同一层只从当前学习窗口抽新卡。
2. 词例离线化：内置 1274 个常用词/短语，不再依赖打开页面时联网下载。
3. 例句按词语类别生成不同使用语境，并可单独播放词或整句；句子粤拼默认折叠。
4. 手机优先布局：底部导航、较大触控区、学习评分条靠近拇指位置。
5. PWA：index.html + manifest.webmanifest + sw.js。部署到 HTTPS 后可“添加到主屏幕”，首次打开后可离线使用。

直接使用
- 电脑：双击 CantoCards_v0.3.html。
- 手机临时使用：把 CantoCards_v0.3.html 传到手机后用浏览器打开。不同手机对本地 HTML 的学习记录持久化支持不同，因此长期通勤使用更建议 PWA。
- PWA 长期使用：把本文件夹部署到任意 HTTPS 静态网站（GitHub Pages / Cloudflare Pages / Netlify / Vercel 均可），再在手机浏览器“添加到主屏幕”。

数据与准确性
- 目标字粤拼：来自用户提供的香港教育署（1992）《常用字廣州話讀音表》的建议读音。
- 离线例词：AI 辅助整理。若词中所有字在原表只有一个建议读音，则完整词粤拼由原表自动拼合；常见多音词/粤语口语词使用内置指定读音。
- 系统发音：仍由设备的 zh-HK / Cantonese TTS 提供；多音字优先读完整词或句子。
- 例句：主要用于记住词的常见使用场景，不视为词典规范例句。

进度兼容
- 继续使用原来的本地存储键，因此同一浏览器打开 v0.3 时会沿用 v0.1/v0.2 的学习记录。
- 换设备前请在“设置与数据”导出进度 JSON，在手机端再导入。
